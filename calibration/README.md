# Calibration Aeon Scorer v3

Le benchmark reproductible utilise 15 précons Commander officiels, 15 listes cEDH publiques et jusqu’à 12 listes Archidekt personnelles/publices comme cohorte intermédiaire.

Le dernier run validé a chargé 38 decks (15 + 15 + 8) et a passé **12/12 gates étendus** après calibration.

Les rapports `latest.json` et `latest.md` sont générés comme artifacts GitHub Actions. Les médianes observées (49 précon / 57 cohorte intermédiaire / 78 cEDH) sont des repères de corpus, jamais des seuils de classement.
