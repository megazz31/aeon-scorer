# P2–P7 V2 validation scope

This branch is a stacked follow-up to `product-p2-p7-roadmap`.

It is intentionally product-layer only and must not alter semantic card evaluation or Aeon core power coefficients.

Validation goals:

- Adaptive Rule 0 answers change only an explicit product-intent overlay.
- Objective deck capability remains unchanged by subjective answers.
- Pod Repair suggestions improve total current-objective mismatch and preserve one player per seat.
- Aeon Reality can be submitted from Aeon Match tables using the exact pre-game prediction shown for that table.
- All new behavior is deterministic where inputs are deterministic.
- Full P2–P7 quality suite remains green.
- Final semantic integration is a separate mandatory gate.
